## 6. Деплой (GitHub Pages)

1. GitHub → `antony-the-dev/kate_onokalo` → **Settings → Pages**
2. Source: **Deploy from a branch** → `main` → `/(root)` → Save
3. Оновлення сайту: будь-який `git push` у `main` передеплоює автоматично.
4. **Домен:** Settings → Pages → **Custom domain** (наприклад `onokalo.art`) → у DNS домену додати CNAME `antony-the-dev.github.io`.

## 7. Як Катерина керує контентом

1. Відкрити `/admin.html` → увійти (email + пароль із розділу «Креди»).
2. Вкладки: **Картини** / **Листівки і закладинки** / **Подарункові бокси** / **Зали**.
3. **Додати** → фото (стиснеться сама), назва, ціна, розмір, зала (для картин), опис.
4. Кнопки у списку: `↑ ↓` — порядок, **Сховати** — прибрати з сайту, **Видалити**.
5. Зміни з'являються на сайті одразу (без деплою).

## 8. Налаштування Supabase (зроблено частково)

Виконано: проєкт, таблиця `items`, політики RLS (читання — публічне, запис — лише авторизований), Storage-бакет `items`, користувач адмінки.

**Ще потрібно (для «Зал»)** — виконати в Supabase → SQL Editor:
```sql
create table if not exists public.halls (
  id uuid primary key, num text, name text not null, name_en text,
  note text, note_en text, sort_order integer not null default 0
);
alter table public.halls enable row level security;
create policy "halls public read" on public.halls for select using (true);
create policy "halls auth write" on public.halls for all to authenticated using (true) with check (true);
grant usage on schema public to anon, authenticated;
grant select on public.halls to anon;
grant select, insert, update, delete on public.halls to authenticated;
```
