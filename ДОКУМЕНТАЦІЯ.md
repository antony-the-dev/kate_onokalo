## 6. Деплой (GitHub Pages)

1. GitHub → `antony-the-dev/kate_onokalo` → **Settings → Pages**
2. Source: **Deploy from a branch** → `main` → `/(root)` → Save
3. Оновлення сайту: будь-який `git push` у `main` передеплоює автоматично.
4. **Домен:** Settings → Pages → **Custom domain** (наприклад `onokalo.art`) → у DNS домену додати CNAME `antony-the-dev.github.io`.

## 7. Як Катерина керує контентом

1. Відкрити `/admin.html` → увійти (email + пароль із розділу «Креди»).
2. Вкладки: **Картини** / **Листівки і закладинки** / **Подарункові бокси** / **Реалізовані проєкти** / **Зали** / **Налаштування**.
3. **Додати** → фото (стиснеться сама), назва, ціна (0 = «ціна за запитом»), розмір, зала (для картин), опис. У «Реалізованих» — лише фото, можна кілька за раз.
4. Кнопки у списку: `↑ ↓` — порядок, **Сховати** — прибрати з сайту, **Видалити**.
5. Зміни з'являються на сайті одразу (без деплою).

## 8. Налаштування Supabase

Виконано: проєкт, таблиці `items` і `halls`, політики RLS (читання — публічне, запис — лише авторизований), Storage-бакет `items`, користувач адмінки.

**Ще потрібно (один раз, для «Реалізованих проєктів» і Etsy)** — Supabase → SQL Editor → вставити й виконати:
```sql
-- 1) Налаштування сайту: текст над «Реалізованими проєктами», посилання на Etsy
create table if not exists public.settings (
  key text primary key,
  value text not null default ''
);
alter table public.settings enable row level security;
drop policy if exists "settings public read" on public.settings;
create policy "settings public read" on public.settings for select using (true);
drop policy if exists "settings auth write" on public.settings;
create policy "settings auth write" on public.settings for all to authenticated using (true) with check (true);
grant select on public.settings to anon;
grant select, insert, update, delete on public.settings to authenticated;

-- 2) Дозволити новий розділ items.cat = 'projects' (знімає старе обмеження на cat, якщо воно є)
do $$
declare c text;
begin
  for c in
    select conname from pg_constraint
    where conrelid = 'public.items'::regclass and contype = 'c'
      and pg_get_constraintdef(oid) ilike '%cat%'
  loop
    execute format('alter table public.items drop constraint %I', c);
  end loop;
end $$;
```
Без цього скрипта сайт працює (показує стандартний текст, Etsy прихований), але в адмінці не збережуться текст і посилання, а фото в «Реалізовані» можуть не додатися.

**Фото.** Адмінка стискає фото в браузері (1600px + мініатюра 800px; WebP, а на iPhone — JPEG) і зберігає як `<id>/<мітка>-<ширина>x<висота>-full.webp` і `…-thumb.webp`. Кожне завантаження — новий файл (без конфліктів і застарілого кешу), старий видаляється. Старі фото (до вересня 2026 — PNG по 1–3 МБ) перестискаються кнопкою в адмінці: **Налаштування → Оптимізація фото**.
